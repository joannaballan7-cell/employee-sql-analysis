# Employee Database Analysis

## Project Overview

This project uses SQL to analyze employee demographic and salary data. The goal is to answer business questions about employee compensation, workforce demographics, and salary trends.

## Tools Used

- MySQL
- SQL
- GitHub

## Business Questions

This analysis answers:

1. What is the average employee salary?
2. Who are the highest-paid employees?
3. How many employees are in each gender group?
4. What salary trends can be identified?

## SQL Skills Demonstrated

- SELECT statements
- Filtering with WHERE
- Sorting with ORDER BY
- Aggregate functions
- GROUP BY
- Data analysis

## Project Files

- `SQL_Queries.sql` - Contains all SQL queries used for analysis
